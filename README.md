# 👋 Hi, I'm Dae'juan Graham!

## 🚀 **About Me**
I'm a data and software engineer drawn to controversial questions, the kind people argue about on instinct. I'd rather settle them with evidence, so I build tested pipelines and models that turn messy data into answers people can trust.

## 🔧 **What I Do**

- **Data Analysis & Engineering** – Built **GridironIQ**, an NFL analytics platform on Databricks that tests which positions actually win Super Bowls in the salary-cap era
- **Machine Learning** – Built **Undercurrent**, an explainable credit-scoring model that judges small businesses on cash flow instead of credit scores
- **Full-Stack & Computer Vision** – Built **Solar Lead Finder**, a live app that spots homes without solar panels from satellite imagery

## 🤖 **How I Use AI**
I build with AI tools like **Claude Code** on purpose: I use them to move faster, while I own the design, review every change, and let tests decide what ships. That's why Claude shows up as a contributor on my repos.
